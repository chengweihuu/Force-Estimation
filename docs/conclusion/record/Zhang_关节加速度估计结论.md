# Zhang关节加速度估计：高阶结构的收益与边界

**UR5／MuJoCo适配和约定实验已完成。GM与HODO组合有条件性收益，但三层没有全面优于两层；这种反向排序应保留，不能靠继续调参把它“修成”论文方法获胜。**

本页保留固定参数下的探索性结论。旧原始日志和实验曲线已清理，本文仅保留已有数值表、结论与边界。后续125 Hz三方法估力比较另见[三方法对比结论](../Observer_Comparison/三种观测方法对比结论.md)，与这里的加速度消融分开阅读。

## 方法与比较设计

输入实际关节位置、速度和驱动力矩，先由名义动力学得到加速度，再由广义动量观测器GM补偿扰动，最后由HODO跟踪剩余加速度扰动及其变化率。**最终输出是关节加速度，GM力矩残差是中间量。**

| 项目 | 本阶段设置 |
|---|---|
| 五组方法 | 名义动力学、仅GM、无GM的HODO、GM＋两层、GM＋三层 |
| 采样与物理 | 主要1 kHz观测、16 kHz物理；另有限定2 kHz对照 |
| 受扰工况 | 主要激励J2，保留闭环控制；六轴均评价 |
| 测量与参考 | 直接读取仿真速度；瞬时qacc只作评价；无事后滤波或时间平移 |
| 参数公平性 | 同一反馈、固定增益；移除第三层回答结构增量作用，没有匹配带宽或噪声水平 |
| 额外检查 | 原七场景含十种子速度噪声、单独黏性补偿失配及限定采样周期对照；0.5／2／3／4 Hz补测仅为准确模型无噪声 |

## 频率结果：三层只在部分已测频点更好

以下为准确模型、无噪声、J2在2—8 s窗口的加速度RMSE，单位rad/s²，不含启动窗口。

| 扰动 | 名义动力学 | 仅GM | 无GM的HODO | GM＋两层 | GM＋三层 |
|---|---:|---:|---:|---:|---:|
| 0.5 Hz | 0.70704786 | 0.04313696 | 0.00191258 | 0.00185860 | 0.00186995 |
| 1 Hz | 0.70705 | 0.08598 | 0.00463 | 0.00315 | 0.00267 |
| 2 Hz | 0.70705 | 0.16889 | 0.02138 | 0.00900 | 0.00743 |
| 3 Hz | 0.70705 | 0.24472 | 0.05674 | 0.02195 | 0.02468 |
| 4 Hz | 0.70705 | 0.31204 | 0.10722 | 0.04314 | 0.05519 |
| 6 Hz | 0.70705 | 0.41980 | 0.22532 | 0.10920 | 0.14471 |
| 7 Hz | 0.70705 | 0.46136 | 0.28185 | 0.15100 | 0.19515 |
| 8 Hz | 0.70705 | 0.49602 | 0.33305 | 0.19568 | 0.24471 |
| 6–8 Hz扫频 | 1.41450 | 0.92183 | 0.56604 | 0.30576 | 0.39282 |

- 在九个已测受扰场景的J2上，组合方法优于仅GM和无GM的HODO；不能外推为全关节普遍优势。
- 三层在1、2 Hz较低；两层在3、4、6、7、8 Hz和扫频较低。0.5 Hz也是两层略低，但差值仅0.00001135 rad/s²，核心窗口仅三个周期，不把它当作普遍应用优势。
- 2 Hz时三层仅J2优于两层，其余五轴RMSE增加约0.00000025—0.00001439 rad/s²；3、4 Hz两层六轴均较低，明显差异集中于J2；0.5 Hz两层六轴略低，差值约0.00000011—0.00001249 rad/s²。

**不能简单概括为“低频三层、高频两层”，也没有确定完整系统的唯一交叉频率。**

## 幅值与相位：改善一个分量，不保证总误差下降

下表是同窗谐波拟合的已有结果。幅值比理想值为1，相位差理想值为0；正相位表示拟合超前，不等于预测能力。

| 频率／Hz | 两层幅值比 | 三层幅值比 | 两层相位差／° | 三层相位差／° |
|---|---:|---:|---:|---:|
| 2 | 1.0172 | 1.0113 | 0.078 | 0.483 |
| 3 | 1.0387 | 1.0323 | 0.410 | 1.709 |
| 4 | 1.0750 | 1.0850 | 0.256 | 2.468 |
| 8 | 1.257 | 1.335 | -8.61 | -9.27 |

| 条件 | 对结果的解释 |
|---|---|
| 1 Hz | 三层幅相均更准，J2总RMSE较低。 |
| 2 Hz | 三层幅值更准、相位更差，但总RMSE仍降低约0.00157 rad/s²。 |
| 3 Hz | 三层幅值更准、相位偏差更大，总RMSE增加约0.00273 rad/s²。 |
| 4 Hz | 三层幅相均更差，总RMSE增加约0.01205 rad/s²。 |
| 6 Hz | 三层相位较好，却有更大的幅值偏差，总RMSE较高。 |
| 8 Hz | 三层幅值放大和相位偏差都更大。 |
| 0.5 Hz | 三层拟合幅相略好，总RMSE却略高；单频拟合没有覆盖全部时域误差。 |

这些是代数与状态描述，不是各分量对总MSE的精确归因。不能统一归咎于“延迟”或“幅值放大”。

## 补偿、噪声与采样是三个不同问题

| 对照 | 已有数值或结论 | 不能据此推出 |
|---|---|---|
| 准确模型、无未知外力 | 同帧名义动力学接近仿真数值精度，增加观测校正反而引入误差 | 真实机器人也有同等模型精度 |
| 黏性补偿低估20%、无力运动 | J6加速度误差从名义模型6.32331降至三层0.03248 rad/s² | 已分离纯接触力与内部误差 |
| 静止速度白噪声0.001 rad/s | 十种子J2均值：仅GM 0.04961、三层0.17744 rad/s²；J1—J5三层较差，J6改善 | 三层全面抗噪，或该噪声代表UR5实测水平 |
| 无力运动1→2 kHz | 三层J6误差0.03248→0.01605 rad/s² | 已唯一定位离散误差来源或完成精度验收 |
| 8 Hz、2 kHz公共1 ms网格 | J2两层0.19432、三层0.24062 rad/s² | 高频反向排序只因原来运行在1 kHz |

采样率对照同时改变观测器积分和输入保持，尚未分离各自贡献。**扰动补偿能力和抗测量噪声能力不是同一个收益。**

## 简化理论支持什么

固定增益形成的频率响应，是排序变化的一个有依据解释，但尚不是完整非线性系统的唯一因果解释。令GM后剩余加速度 $w_*=\ddot q-f_*$、估计误差 $e_a=\widehat{\ddot q}-\ddot q$。只保留连续线性校正、假定准确速度和相同 $w_*$，考察零初值或稳态响应，有：

$$
\frac{E_2(s)}{W_*(s)}=-\frac{s^2}{s^2+120s+4800},\qquad
\frac{E_3(s)}{W_*(s)}=-\frac{s^3}{s^3+120s^2+4800s+64000}.
$$

三层分母为 $(s+40)^3$。此前简化模型给出的三层／两层误差幅值比，在0.5、1、2、3、4、8 Hz分别为0.234、0.456、0.832、1.087、1.227、1.222；理论相等点为：

$$
f_c=\frac{1}{2\pi}\sqrt{\frac{64000}{2\times120}}\approx2.60\ \mathrm{Hz}.
$$

它支持2—3 Hz之间的主要排序趋势，但**2.60 Hz不是完整仿真已确认的切换阈值**；输入是GM之后的剩余扰动，也不是原始外力。0.5 Hz实际排序与简化模型不同，且差异很小。平方根／符号校正、离散更新、背景运动和有限窗口仍是候选解释，尚未确定各自贡献。

## 与论文及后续应用的边界

| 边界 | 应保留的判断 |
|---|---|
| 结构与整定 | 原文单关节消融关闭外力补偿；本页主要比较UR5的GM＋两层／三层。共同增益不等于等带宽、等噪声或各自最优，两层消融也不能冒充原文引用的另一完整算法。 |
| 激励与测量 | 本项目通过Plant惯性矩阵将J2等效加速度换成关节扰动力矩，保留闭环运动；直接仿真速度、瞬时qacc与未滤波输出，不等于论文的位置差分测量、零相位参考及统一50 Hz五阶输出低通。 |
| 理论保证 | 原文特定实验优势不保证任意参数或频率更好；连续稳定性也不保证离散RMSE排序。有限时间论证未独立验证，附录中的扰动导数及变参数Lyapunov论证保留为理论边界。 |
| GM含义 | 模型失配也进入GM残差，补偿有效不等于准确辨认了纯外力。 |
| 覆盖范围 | 六轴有评价，但受扰主要是J2。没有全面覆盖独立六轴受扰、姿态、真实接触、真机、在线频率识别、观测器切换或幅相补偿；后续125 Hz估力比较另行归档。 |

原文式（18）的打印符号与式（17）求导及一阶低通描述不一致；既有实现采用稳定形式 $\dot r=K_m(\tau_{ext}-r)$。这是此前已核对的实现选择，不是本次整理修改算法，也不声称作者发布了勘误。论文§V-B按相同输出噪声整定的比较，本阶段没有复刻。

保留三个问题：高阶状态如何改变跟踪、幅相与噪声的取舍；瞬时加速度目标与离散反馈可支持的变化率如何对应；GM＋HODO补偿的是总扰动还是可辨认的物理来源。暂不确定后续研究方向，不为让三层获胜而继续调参。
