# 动量KF：已完成什么，主要问题是什么

**基础动量KF已跑通。当前主要问题是误差信息如何进入并被分配到外力估计，尚未发现明确的递推或协方差实现错误。原KF保留为基线，区间平均模型保留为候选认识，没有全面更优的默认配置。**

本页是既有UR5／MuJoCo、125 Hz测试的探索性总结。历史逐样本记录已清理，保留方法结论与适用边界。后续三方法比较集中在[三方法对比结论](../Observer_Comparison/三种观测方法对比结论.md)，不在这里重复排名。

## 误差在哪里形成

动量测量与已知输入由同一组关节反馈构造。新息通过wrench增益块映射成六维校正：

$$
r_k=y_{p,k}-\widehat p_k^-,\qquad
\Delta\widehat w_k=K_{w,k}r_k,\qquad
\widehat w_k^+=\widehat w_k^-+\Delta\widehat w_k.
$$

- 同轴过校正和跨轴假力可在新息分配时形成，随后递推使其消退。雅可比满秩不保证瞬态解耦。
- 准确离散对照中超调和串扰仍存在，不能仅归因于8 ms输入保持、传统辨识误差或J6机械特性。外力过程模型与协方差形成的估计动态是重要来源，但不是已证实的唯一根因。
- 协方差审计未发现明确实现错误；冻结系数模型的过程噪声离散化与交叉块处理一致。噪声强度仍是人工假定，改变相对权重会同时改变通道分配及响应代价。

## 两种输出不能混为一谈

| 对象 | 已确认的含义 | 边界 |
|---|---|---|
| 原KF | 以连续随机游走为先验，估计采样时刻的末端外力 | 输出仍受估计动态影响，不等于无延迟真值 |
| 区间模型 | 明确估计上一采样区间平均外力 | 区间中心不是结果可用时刻，也不是当前瞬时外力 |
| 固定整包延迟 | 正确保留采样时间戳时，同一历史估计不变，结果更晚可用 | 对当前真值的误差仍增加；不能据此宣布实时性能不变 |
| 在线与确定性重放 | 相同反馈与更新顺序给出相同估计 | 不证明模型准确，也不构成硬实时保证 |

区间模型在已测对齐阶跃、半周期错位阶跃和主动运动中，降低了关注的超调及My→Fx峰值；但串扰仍在，部分其他通道变差、部分响应变慢，正弦当前瞬时误差可能增加，无力运动偏差没有消失。它改变的是目标与过程先验，不是给原输出改名。

时变雅可比下，区间平均力也不能一般地精确代替区间内广义力积分。125 Hz的影响同时包含输入保持、估计动态与采样分辨率，尚未唯一分离。

## 单因素测试留下的结论

| 误差来源 | 已有结论 |
|---|---|
| 速度／驱动力矩随机噪声 | 均可形成六维波动；区间模型降低部分噪声传递，但有动态滞后代价。幅值拟合准确不代表瞬时输出干净。 |
| 力矩固定偏置／比例误差 | 形成持续或运动相关假力，两种模型均不能自动消除。比例误差影响取决于实际驱动力矩，不能只看百分数。 |
| 工具负载误配 | 形成重力相关假力，平滑和外力先验不能替代负载标定。 |
| 连杆转动惯量误差 | 质量、质心不变时，静止检查可能看不出问题；小幅运动低敏感性不证明惯性准确。 |
| 黏性摩擦补偿误差 | 形成速度相关假力。静止为零或换向后残留，都不足以证明齿隙；没有验证真实换向机械误差。 |
| 信号不同步 | 破坏动量与输入的时间一致性；配对到共同历史时刻能恢复一致性，但仍有延迟，区间模型未消除该问题。 |
| 不规则采样／丢包 | 按实际间隔递推可正常运行；信息缺失、数据老化和长区间保持仍造成误差。恢复无丢包输出不等于恢复真值。 |
| 因果速度处理 | 同时改变动量测量与速度相关输入，已有比较存在收益和代价，尚不能直接作为默认改进。 |

**持续系统误差与真实外力都能进入同一动量残差；更强平滑不会凭空增加区分两者的信息。** 静态满秩条件下，若测量力矩偏置为 $b_\tau$，其平衡关系为：

$$
J^T\Delta\widehat w=-b_\tau.
$$

这个静态关系不能替代运动中的整个估计动态。

## 覆盖范围与待保留问题

**已完成：** 运动六方向正负覆盖；速度／力矩白噪声、力矩偏置／比例误差、负载／惯量／黏性摩擦误差、采样间隔变化、丢包、信号错配、固定整包延迟及相关机制对照。不能把这些重新列为“未做”。

**尚未充分覆盖：** 代表性组合误差、广泛姿态与近奇异工况、完整外力变化速度范围、独立工具质心误差、真实有色／相关噪声、通信乱序与到达抖动、真实接触及真机。后续三方法实验补充了有限Fz加载速度和噪声对照，不等于这些广泛边界已经解决。

保留三个问题，不据此自动确定研究方向：

1. 有限采样下，当前外力、区间作用量与时变雅可比预测缺陷如何区分？
2. 如何改善动态通道耦合，同时不以更大滞后掩盖偏置或真实接触？
3. 同一速度进入动量测量和预测输入，当前协方差是否充分描述相关误差？
