# Docs：长期研究知识

这里保存可以跨任务保留的研究内容，而不是当前任务状态或探索过程。

| 子目录 | 用途 |
|---|---|
| `ideas/` | 研究问题、Claims、理论和证据入口 |
| `protocols/` | FORMAL 前冻结的验证方法与数据合同 |
| `references/` | 实际影响当前研究的外部资料 |
| `paper/` | 论文直接使用的文字、图表和投稿材料 |

工作流图在 [workflow_architecture.svg](attachment/workflow_architecture.svg)，PNG 用于直接预览。每个子目录
都有自己的 README，先从最贴近你当前目标的一个开始看。

本目录及子目录的 `AGENTS.md` 是 Codex 的局部规则，不是日常阅读入口。
