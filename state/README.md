# State：当前研究控制

这里是你查看“项目目前走到哪里”的地方，不是研究笔记或任务历史。

| 文件 | 你可以从中得到什么 |
|---|---|
| `PROJECT.md` | 稳定的项目目标、边界和技术环境 |
| `CURRENT.md` | 对象指针、一句话接受状态、主要不确定性和下一项决策 |
| `TASK.md` | 正在执行的唯一任务；Inactive 表示目前只适合构思 |
| `EXAMPLES.md` | TASK、Closeout、Experiment 和 run.yaml 的完整填写示例 |

通常先看 `CURRENT.md`；完整科学结论在对应 Idea。TASK 中的 `Progress` 是当前检查点，
`Budget` 约束文件、计算和机器人运行。Closeout 涉及知识时，你会看到拟写入的完整文本或
diff，再决定是否接受。

复制模板后要先建立 Git 初始提交，它是 CURRENT 和 Idea 覆盖更新的回滚安全网。想开始下一步
时，先在对话中 THINK，确认方案后再准备 TASK。

本目录的 `AGENTS.md` 是 Codex 的详细任务规则；`EXAMPLES.md` 也只在需要检查具体格式时读取。
你不需要为了日常理解而先读它们。
