# Physics-informed adaptive Kalman filter for contact force estimation in industrial robots considering model uncertainty — 复现方案

**可以根据现有笔记开始复现。当前材料足以重建主要方程、实现各模块并检验核心机制，但不足以保证复现论文的原始数值结果。** 第一目标应是：在明确记录实现假设的前提下，完成结构化动力学、动量KF、换向误差补偿和变窗口WMA，运行四组消融，检验补偿是否降低假力且保留真实外力。

本文默认沿用库内已有的**Python＋MuJoCo路线**，先仿真再考虑真机。使用替代机器人时，成果称为“基于PIAKF的方法重实现”。若要复现SN7B上的表3、表5或计算时间，需要进一步匹配作者的模型、数据、配置和计时条件。

本文件是执行方案，尚未据此安装环境、编写完整程序、训练网络或产生新的实验结果。公式依据为[正式笔记](PIAKF_2026_notes.md)、[论文正文](PIAKF_2026_source.md)与[本地PDF](PIAKF_2026.pdf)。较详细的接口说明和KF代码骨架另见[既有MuJoCo指南](../../../Scratch/no_sensor/PIAKF_MuJoCo_Reproduction_Guide.md)；其中环境状态与历史自检记录仅代表其记录时点。

## 1. 现有笔记支持哪一种复现

| 层次 | 要得到的成果 | 现有材料是否足够 |
|---|---|---|
| 方程与程序自洽 | 动量关系、补偿符号、KF递推、噪声离散化、WMA实现正确 | 基本足够；按笔记中的修读和条件实现 |
| 方法结构与机制重实现 | 学习动力学＋TCN／Gaussian补偿＋WMA，并完成四组消融 | 可以开始，但必须填清未披露配置；结果取决于这些选择 |
| 原论文数值复现 | 相同数据与工况下重现表3、表5及计算耗时 | 尚不够；缺模型细节、原始数据、标签流程及完整参数 |

论文仿真平台是MATLAB/Simscape，真机是SIASUN SN7B；原文仿真明确使用黏性摩擦，真机实验进一步检验换向误差。因此，MuJoCo中新增显式齿隙属于复现中的机制实验，不能称为作者原有仿真设置。（论文§4.1—4.2；[笔记附录H](PIAKF_2026_notes.md#appendix-h)）

几个需要预先区分的结果：

- 仅实现解析动力学＋KF，得到的是基础观测器，不是完整PIAKF。
- 向日志添加一个Gaussian峰，只能检验信号处理；让扰动实际作用于机器人运动，才能检验动力学与估计器的耦合。
- 合成Gaussian扰动被同形补偿器消除，不证明一般齿隙都能被补偿。
- 仿真中的估力改善，不等于真机装配成功率改善；后者还需要独立的闭环任务验证。

## 3. 按六个阶段推进

实施顺序为：**同步测量与外力接口 → 基础动量KF → 学习动力学 → 换向补偿 → 四组消融 → 泛化与真机日志。** 每阶段先通过自己的检查，再引入下一种误差来源。

| 阶段 | 需要实现的工作 | 必须留下的结果 | 进入下一阶段的条件 |
|---|---|---|---|
| A 接口 | 加载机器人、施加已知外力、记录测量与独立参考 | 无外力和受力日志、模型版本、坐标约定 | 外力实际进入物理推进；符号、参考点、时间戳一致 |
| B 基础KF | 独立名义动力学、动量测量、12维KF；可加GMO排错 | 无外力、恒力、正弦力曲线及数值自检 | 不使用真值输入即可估力；主要残差能定位到模型、噪声或动态响应 |
| C 学习动力学 | 激励采集、结构网络、摩擦学习及冻结 | 训练划分、权重、留出轨迹误差 | 不仅力矩拟合可用，接入KF后的估力也可用 |
| D 换向补偿 | 误差标签、TCN、Gaussian参数MLP、因果事件管理 | 事件与波形指标、补偿前后曲线 | 符号和时基正确；同时检查假力抑制与真实力保留 |
| E 完整消融 | PIKF、PIKF-C、CW1、CW2重放同一数据 | 每轴RMSE／SD2／动态响应及失败记录 | 能解释补偿作用与滤波位置差异，不靠测试集调参 |
| F 泛化与迁移 | 未见轨迹、负载、误差形态、接触；有条件再做真机 | 分工况统计、重复试验、偏离表 | 结果不依赖单条轨迹或同一种合成波形 |

**首个里程碑定在阶段B。**先拿到“已知外力、允许测量、估计输出”能够对齐的日志和曲线，再投入神经网络训练。做到阶段E才具备报告完整方法重实现的基本条件。

## 4. 准备环境并固定信息边界

### 4.1 代码项目与依赖

将训练代码、机器人资产、数据和模型权重放在独立代码项目，例如`piakf_reproduction`；本文件继续保存在论文包内。以下是待执行的环境命令，不表示当前已安装这些依赖。进入选定的代码项目后运行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install mujoco numpy scipy matplotlib pyyaml
python -m pip freeze > requirements-lock.txt
python -c "import mujoco; print(mujoco.__version__)"
```

官方`mujoco` Python包包含MuJoCo库；学习阶段再按操作系统和CPU／GPU条件安装PyTorch，并更新依赖锁定文件。本文MuJoCo机制说明以3.3.7文档为依据，实际代码必须按安装版本核对API。[MuJoCo安装说明](https://mujoco.readthedocs.io/en/3.3.7/python.html#installation)、[PyTorch安装入口](https://pytorch.org/get-started/locally/)

缺少SN7B模型时，可沿用既有指南中的[Menagerie UR5e模型](https://github.com/google-deepmind/mujoco_menagerie/tree/main/universal_robots_ur5e)。记录模型commit、资产、许可证和本地改动。不要把另一台机器人的惯量、负载和误差水平视为SN7B的等价替代。

建议起点为物理步长0.5 ms、控制与观测周期1 ms、关闭渲染、固定基座六轴、无活动夹爪；这些是实施选择。正式结果再将物理步长减半，检查结论是否改变。仿真时间以1 kHz推进，不代表代码已达到1 kHz墙钟实时性。

### 4.2 必须分开仿真对象和估计模型

建立独立的`plant_model/plant_data`与`nominal_model/nominal_data`。前者产生运动和接触，后者只用可用反馈计算名义模型量。

| 数据 | 在线估计器可用性 |
|---|---|
| 关节位置、速度、电流或声明的力矩测量代理 | 可用；噪声、偏置、时延必须可追踪 |
| 从上述信号因果得到的加速度及历史 | 可用；不能包含未来样本 |
| 离线冻结的动力学、摩擦和补偿参数 | 可用 |
| 仿真真实外力、接触标签、真实间隙状态 | 仅评价或明确标注的诊断实验 |
| 仿真真实惯性、加速度与内部误差 | 仅诊断或独立标注的教师实验，不作为正常估计输入 |

首轮可从`qfrc_actuator`构造驱动力矩测量代理，称为`torque_proxy`；它尚未模拟真实电流反馈链。`ctrl`的含义取决于执行器定义，位置伺服模型中不能把它当作关节力矩。原生动力学中的驱动、被动力和偏置力是不同量，应分别处理。[MuJoCo动力学与驱动定义](https://mujoco.readthedocs.io/en/3.3.7/computation/index.html#actuation-model)

同模型、无噪声可用作程序自检。正式机制实验再引入模型失配和测量限制，否则只检验了方程在相同模型下的一致性。

### 4.3 首先固定坐标、符号与时间

首版令wrench在世界坐标轴下、关于指定工具点表达，分量顺序为$[F_x,F_y,F_z,M_x,M_y,M_z]^T$，雅可比采用匹配顺序。规定外力为“环境作用于机器人”的力，检查

$$
\tau_{ext}=J^T\omega,
\qquad \tau_{ext}^Tv=\omega^T Jv.
$$

同一时刻的$q,v$、驱动力矩和参考力必须对应同一物理状态。每个物理步重新组装外力，避免累加旧值；内部合成扰动与末端外力使用独立数组记录。估计器接口只接收测量包，评价器另接收参考，便于检查真值是否意外进入算法。

## 5. 先实现可以独立检查的动量KF

### 5.1 用同一个名义模型构造动量与输入

首版先用独立解析／仿真名义模型，后续换成学习模型，保持接口相同：

```text
nominal.evaluate(q, v) -> M_hat, Mdot_hat, h_hat, friction_hat, J
compensator.update(history) -> error_hat, event_score
observer.update(measurement_packet) -> wrench_hat, covariance, diagnostics
```

记$v=\dot q$、$a=\ddot q$、$\widehat h=\widehat c+\widehat G$、$\tau_m$为测得或代理的驱动力矩。统一采用

$$
p=\widehat M(q)v,
\qquad H=\dot{\widehat M}v+\tau_m-\widehat\tau_{fri}-\widehat h,
$$

$$
\dot p=H+J^T\omega-\tau_{err},
\qquad H_e=H-\widehat\tau_{err}.
$$

这里$p$是名义动量状态，测量为$y=\widehat M(q_m)v_m$；两者不能混用不同模型。未接入补偿时令$\widehat\tau_{err}=0$。补偿已在$H$中扣除后，不再从最终力估计中按同一符号扣一次。

调试时可用名义模型的方向有限差分求$\dot{\widehat M}$；进入完整学习阶段改为网络链式导数。不能把原文的速度二次紧凑记号写成逐元素$v^2$。（[笔记附录A—B](PIAKF_2026_notes.md#appendix-a)）

### 5.2 离散状态与噪声

先选$S=0$；一个采样区间内冻结$D=J^T$，令$T_s$为观测周期：

$$
x=\begin{bmatrix}p\\\omega\end{bmatrix},\qquad
A=\begin{bmatrix}I_n&T_sD\\0&I_m\end{bmatrix},\quad
B=\begin{bmatrix}T_sI_n\\0\end{bmatrix},\quad
C=\begin{bmatrix}I_n&0\end{bmatrix}.
$$

首版$n=m=6$。连续噪声强度$Q_c=\operatorname{diag}(Q_p,Q_\omega)$对应

$$
Q_d=\begin{bmatrix}
T_sQ_p+\frac{T_s^3}{3}DQ_\omega D^T&\frac{T_s^2}{2}DQ_\omega\\
\frac{T_s^2}{2}Q_\omega D^T&T_sQ_\omega
\end{bmatrix}.
$$

采用标准KF预测、动量创新和校正：

$$
\widehat x_k^-=A_k\widehat x_{k-1}^++B_ku_{k-1},\qquad
P_k^-=A_kP_{k-1}^+A_k^T+Q_{d,k},
$$

$$
r_k=y_k-C\widehat x_k^-,\qquad
K_k=P_k^-C^T(CP_k^-C^T+R_k)^{-1},\qquad
\widehat x_k^+=\widehat x_k^-+K_kr_k.
$$

实现中通过解线性方程计算增益，协方差优先用Joseph形式。初始化$\widehat x_0=[y_0^T,0^T]^T$，并给外力状态非零初始不确定性；检查$P$对称、半正定。具体骨架见[既有指南§6](../../../Scratch/no_sensor/PIAKF_MuJoCo_Reproduction_Guide.md#kf)，推导见[笔记附录C—D](PIAKF_2026_notes.md#appendix-c)。

### 5.3 调参与在线顺序

$Q_p$处理动量方程误差，$Q_\omega$允许外力变化，$R$对应虚拟动量测量误差。若暂只考虑速度噪声，可从$R=\widehat M\Sigma_v\widehat M^T$起步。连续强度与离散方差不能直接互换；力和力矩的尺度也应分开。

工程分支可指定每步外力增量标准差$s_{\Delta\omega}$，再用$Q_\omega=\operatorname{diag}(s_{\Delta\omega}^2)/T_s$生成候选值。在验证集上同时比较无外力波动和受力响应，选定后冻结，不能只按测试集RMSE选参。

```text
初始化：构造y0、x0、P0，以及首个可用输入u0。
每个采样时刻tk：
  1. 读取同步测量包。
  2. 用上一采样区间的J、u、Q传播到tk。
  3. 构造当前y与R，以动量创新校正状态，输出wrench估计。
  4. 更新因果加速度和历史窗口，得到当前误差预测。
  5. 构造当前H、He，按算法版本处理，得到下一段使用的u。
  6. 保存测量时刻、可用时刻、输出时刻与中间量。
```

这种$u_{k-1}$约定对应区间零阶保持，不能仅凭下标认定额外延迟一周期。固定$J$、$S=0$时完整wrench可观测要求$\operatorname{rank}(J^T)=m$；首轮避开奇异姿态，并记录测试轨迹的退化区段。

## 6. 再用结构化网络替换名义动力学

### 6.1 准备训练与留出数据

以无外部接触运动采集$q,v,\tau_m$及离线加速度参考。工具和载荷是否属于名义机器人必须先确定；否则未建模负载会混进“内部误差”标签。

原文是12条10 s五阶Fourier轨迹、1 kHz、总120,000点，离线双向五阶Butterworth滤波、截止50 Hz，再由速度数值微分获得加速度。采用不同机器人时，重新生成满足该模型运动和力矩约束的轨迹；不能宣称恢复了未公开的原轨迹系数。（论文§4.2；[笔记附录G](PIAKF_2026_notes.md#appendix-g)）

第一轮按整条轨迹8／2／2划分训练、验证、测试，明确其与原文随机样本划分不同。归一化统计、事件阈值和滤波选择只用训练／验证数据；历史窗口不跨轨迹与数据集合。在线输入用冻结的因果处理链，不能直接使用双向滤波后的未来信息。

### 6.2 实现结构与损失

网络从$q$输出下三角因子$L$与重力向量$\widehat G$。六轴时$L$有21个独立元素：

$$
\widehat M=LL^T,\qquad
\widehat T=\tfrac12v^T\widehat Mv,\qquad
\widehat\tau_{dyn}=\widehat Ma+\dot{\widehat M}v-\nabla_q\widehat T+\widehat G.
$$

按第2节的已报告网络配置起步，采用已声明的对角正值约束。求导针对物理单位的$q$；网络若归一化输入，要保留链式缩放因子。先用自动微分实现正确性，再比较显式链式计算耗时，不将二者的数学原理混淆。

摩擦按PDF式(17)—(18)保留基函数次序：

$$
\widehat\tau_{fri,j}=\operatorname{sign}(v_j)
\left[f_{c,j}\lambda_j+f_{v,j}(1-\lambda_j)+f_{b,j}|v_j|^{\alpha_j}\right],
\qquad
\lambda_j=\exp\left[-|v_j/v_{s,j}|^{\delta_j}\right].
$$

原文参数名称与基函数含义不完全对应，不能仅凭名称改写。明确正值参数化、零速规则与是否要求耗散；更换平滑sign或引入摩擦内部状态，应另列为变体。名义侧的摩擦只计一次。

无外部作用、或已明确处理外部作用时，可采用下列重建监督目标：

$$
\mathcal L_{dyn}=\frac1N\sum_k
\left\|\widehat\tau_{dyn}(q_k,v_k,a_k)+\widehat\tau_{fri}(v_k)-\tau_{m,k}\right\|^2.
$$

这是可实施的损失重建，作者未披露完整训练总损失与全部约束。训练时采用验证集早停，记录实际规则和轮数。

### 6.3 不只验收力矩拟合

在留出轨迹同时检查：各关节力矩误差、惯性正定性、链式导数与有限差分、两种等价$H$表达的一致性，以及模型接入KF后的估力。Plant真实惯性可作独立诊断，不能隐含加入正常训练监督。

冻结动力学和摩擦模型后再生成补偿标签。之后若修改名义模型，必须重建残差标签并重新训练或验证补偿器。

<a id="compensation"></a>

## 7. 换向误差补偿是最需要补齐假设的一环

### 7.1 先让误差实际存在，再生成标签

在已有物理仿真中依次加入参数失配、合成换向扰动，必要时再加入显式传动间隙。若把内部扰动$d_{int}$定义在动力学左侧，应向物理推进施加$-d_{int}$，并与末端外力分开记录。合成扰动只是机制排错条件。

显式间隙可从单关节开始。MuJoCo官方示例使用同轴双hinge，一个受驱动，另一个在小范围内相对转动，并设置必要的armature。增加自由度后必须重新检查测量侧别和动力学映射，不能读取真实间隙量来替只有电机编码器的估计器“补齐”测量。[官方Backlash示例](https://mujoco.readthedocs.io/en/3.3.7/modeling.html#backlash)

首版只在无外力训练段构造

$$
\tau_{err}^{label}=\tau_m-\widehat\tau_{dyn}(q,v,a)-\widehat\tau_{fri}(v).
$$

它是相对当前名义模型的残差，不是独立测得的纯齿隙力矩。此处选择逆动力学标签，而论文§3.2末尾还提到观测传播残差；两者的关系未完全披露，因此必须在结果中说明。不能把无接触KF输出直接同号送回输入补偿，跳过符号和动态转换。

### 7.2 先做事件规则排错，再训练TCN

训练段的事件标注可综合速度换向与残差显著区间，明确死区、阈值和持续时间。先用因果换向规则检验符号与波形时序；规则只是调试基线，完整重实现保留TCN。

下面是可用起点，**均为实施选择，非作者已披露结构**：

| 项目 | 起始配置 |
|---|---|
| 输入 | 单关节历史$[q,v,a]$；128个采样点，1 kHz时覆盖128 ms |
| 卷积 | 六层、每层一次因果卷积，32通道、核宽3，膨胀率1／2／4／8／16／32 |
| 输出与训练 | 当前事件概率；二元交叉熵；类别处理策略记录在配置中 |
| 触发 | 验证集确定概率阈值和迟滞；保存实际触发时间 |

上述卷积定义下感受野为127个采样点；若改为每块多次卷积，要重新计算。当前事件分类不能称为事件发生前预测；分别报告起点检测延迟和相对误差峰的提前量。

### 7.3 让Gaussian波形与实际触发时刻一致

以检测器实际触发时刻$\widehat t_{on}$为基准，令$s=t-\widehat t_{on}$：

$$
\widehat\tau_{err}(t)=\widehat a_g
\exp\left[-\frac{(s-\widehat b_g)^2}{\widehat c_g^2}\right].
$$

推荐实施顺序：

1. 冻结TCN，在训练／校准数据上按真实在线规则重放，取得触发时刻。
2. 以这些触发时刻为零点，离线拟合残差波形参数。标签可使用训练记录的后续片段，但在线特征不能含未来信息。
3. MLP只用触发时刻的$q,a$预测参数；可从两层32节点开始。幅值允许正负，宽度保持正值；支持长度、截断和重叠规则一并固定。
4. 在线按各事件时钟生成补偿；漏检或晚检如实记录，不能用真实事件时刻回填已发布输出。

拟合参数监督可先用于初始化，再在波形误差上使用式(44)对应的$e^4+\sigma e^2$进行训练；这条分阶段训练路线是重建方案。若采用该损失，明确权重是否参与反向传播，本方案默认参与。所有参数选择仍限定在训练／验证集。

最先检查补偿方向：$H=5$、$\tau_{err}=3$、无外力时$\dot p=2$；正确补偿应给出$H_e=2$，残差为零。加入外力矩4后$\dot p=6$，补偿后瞬时残差应为4。之后再比较真实KF动态输出。（[笔记附录E](PIAKF_2026_notes.md#appendix-e)）

## 8. 完成变窗口WMA和四组消融

加权移动平均与重置规则为

$$
W_z[s]_k=\sum_{\ell=0}^{z-1}\frac{2(z-\ell)}{z(z+1)}s_{k-\ell},
\qquad z_k=\min(z_{max},k-r+1).
$$

当$|s_k-s'_{k-1}|>\varepsilon$时令$r=k$，当前窗口回到1，再逐步恢复。初始化只用已有历史。本方案先逐关节复位，候选$z_{max}\in\{5,10,20\}$，阈值依据训练数据的无事件波动确定候选，在验证集上选择；这些数值并非论文参数。

令$b=\dot{\widehat M}v-\widehat\tau_{fri}-\widehat h$，四组仅改变KF输入：

| 版本 | 输入$u$ | 用来判断什么 |
|---|---|---|
| PIKF | $b+\tau_m$ | 学习动力学后的基础表现 |
| PIKF-C | $b+\tau_m-\widehat\tau_{err}$ | 显式补偿的收益 |
| PIAKF-CW1 | $b+W[\tau_m]-\widehat\tau_{err}$ | 只滤电流等效力矩的效果 |
| PIAKF-CW2 | $W[b+\tau_m-\widehat\tau_{err}]$ | 补偿后整体滤波的效果 |

CW1在力矩代理上滤波是明确的实现选择。固定电流增益时，要连同阈值一起换算，才可与电流滤波对应。两组采用同一窗口上限、明确的阈值尺度，并保存各自触发历史；相同参数数值不保证相同窗口轨迹。

先用相同动力学、补偿器与KF参数做机制消融，再单独报告公平调参后的性能比较。所有方法重放相同测量数据，保持参考与预处理一致。

论文表5本身显示：CW2更平滑，但平均RMSE高于PIKF-C。3 kg时分别为2.48与2.31 N·m，6 kg时分别为2.88与2.72 N·m。复现的目标是检验并解释这种取舍，不能把“CW2所有指标第一”当成通过标准。（[笔记附录H](PIAKF_2026_notes.md#appendix-h)）

## 9. 实验与指标怎样安排

### 9.1 先跑这些场景

| 场景 | 来源与设置 | 主要问题 |
|---|---|---|
| 无外力静止与平滑运动 | 程序自检；先无噪声，再逐项加误差 | 是否存在符号、重力、摩擦重复计数或同步错误 |
| 静止正弦外力 | 原文图4：X向20 N幅值、0.5 s周期；先确认所用模型可执行 | RMSE、幅值与相位响应 |
| 运动中多轴外力 | 原文图5为20 N和2 N·m量级；具体轨迹和多轴波形自行声明 | 动力学与wrench映射在运动中是否成立 |
| 无接触换向 | 机制实验；相同轨迹比较补偿前后 | 内部误差导致的假力是否下降 |
| 换向附近加力／撤力 | 补充辨别实验；覆盖换向前、同时、之后 | 假力下降是否伴随真实外力被削弱 |
| 持续小力与测量偏置 | 补充低速工况；两者分别设置，再组合 | 是否混淆持续接触与慢变模型误差 |
| 未见轨迹、负载、波形形态 | 留出测试；动力学与补偿权重冻结 | 泛化是否依赖训练覆盖或同形Gaussian模板 |
| 真实表面接触 | 后续压平面、滑动、撤离 | 接触求解参考与估计是否一致 |

原文3／6 kg是SN7B载荷条件。替代机器人重新确定载荷组；还要固定哪些负载已纳入名义模型、哪些作为待估外部作用。表面接触参考应按目标接触对合成、统一坐标和力矩参考点，不能把全部约束力都当作工具接触力。

每个场景保存独立测量与参考。先用一个固定种子排错；正式结果对关键工况使用预先确定的多组种子或独立试验批次，例如20组，报告分布和失败次数。20组只是试验预算建议，不是统计充分性的保证。

### 9.2 同时评价误差、平滑和动态保真

逐方向计算

$$
\operatorname{RMSE}_j=\sqrt{\frac1N\sum_{k=1}^{N}
(\widehat\omega_{j,k}-\omega^{ref}_{j,k})^2}.
$$

力与力矩分别报告单位，关节外力矩另报。原文Average是各方向／工况RMSE的汇总，不能与合并所有误差后再开方混用。

SD2建议对合法二阶差分计算样本标准差。原始序列长$N>3$时，取

$$
d_i=\widehat\tau_{i+1}-2\widehat\tau_i+\widehat\tau_{i-1},\quad
i=2,\ldots,N-1,\quad L=N-2,
$$

$$
\overline d=\frac1L\sum_{i=2}^{N-1}d_i,\qquad
\operatorname{SD2}=\sqrt{\frac1{L-1}\sum_{i=2}^{N-1}(d_i-\overline d)^2}.
$$

这是本方案的明确统计口径；论文式(54)的端点与去均值写法存在疑点，代码未取得前不声称完全一致。SD2没有除以$T_s^2$，单位仍为N·m；降低SD2不等于保住接触峰值。

额外报告无接触偏置与假力峰、接触起点和上升时间、脉冲峰值与冲量、持续力幅值、事件误报／漏报，以及各模块与全链路耗时。主结果保持原时间戳，禁止靠事后平移曲线改善实时RMSE；延迟诊断可另表展示。

表2的2.50 μs仅是惯性导数模块耗时。若比较速度，分别计时惯性导数、网络、WMA、KF与完整采样输出链，并记录设备、批量和同步方式。

## 10. 验收条件和排错顺序

### 10.1 每个阶段先通过这些检查

| 检查 | 可执行的通过条件 |
|---|---|
| 信息隔离 | 估计器只接受测量包与冻结模型；外力真值和隐藏传动状态不进入接口 |
| 力映射 | 指定作用点下，独立外力广义映射与$J^T\omega$一致，虚功符号一致 |
| 动力学自检 | 同模型、无噪声、无额外约束时，惯性／偏置／摩擦与实际驱动力矩平衡；残差随数值精度变化可解释 |
| 惯性与导数 | 惯性对称正定；平滑点的链式导数与有限差分一致，差分步长敏感性已检查 |
| KF代数 | 冻结系数下的$A,B,Q_d$与矩阵指数／积分一致，协方差保持对称半正定 |
| 补偿符号 | 第7节单关节例子通过；外力与换向重叠时单独报告真实力保留 |
| WMA逻辑 | 固定$z=3$，输入从0跳到6后依次输出3、5、6；若立即触发重置，首样本为6 |
| 数据隔离 | 测试轨迹、事件与历史窗未进入训练或选参，所有配置可追溯 |
| 数值敏感性 | 减半物理步长后主要判断保持；接触实验另查合理约束参数范围 |
| 报告完整性 | 有每轴指标、失败案例、实际重复数、实现偏离表及可重放日志 |

良好尺度的双精度代数比较可先用相对误差$10^{-8}$量级排错，平滑点有限差分可从$10^{-4}$量级起步；近零量采用绝对容差，ReLU折点单独处理。这些是程序检查起点，不能当作接触仿真或学习模型的精度要求。

实际性能门槛要在测试前按任务确定，例如允许的假力峰、力跟踪误差和检测延迟。即使完整方法没有复现预期排名，只要实现经过检查并如实报告工况和失败，也不应通过反复调测试集来制造成功。

### 10.2 常见现象先检查哪里

| 现象 | 首先排查 |
|---|---|
| 无接触仍有很大恒定力 | 重力、工具载荷、电流增益、力矩侧别、把`ctrl`误当力矩 |
| 力的方向整体反了 | 作用／反作用、雅可比与wrench顺序、参考点 |
| 静止正常，运动时误差大 | 名义惯性、导数交叉项、反馈时序、奇异姿态 |
| 训练力矩误差低，估力仍差 | 惯性分解是否可用、预处理差异、模型在KF中的误差传播 |
| 补偿后换向峰更大 | 标签符号、事件时间原点、形状参数、在线加速度延迟 |
| KF运行越久越迟钝 | 零外力过程噪声、常值先验、初始协方差与增益变化 |
| CW1明显变差 | 补偿与驱动力矩的相对时序、阈值单位及窗口触发历史 |
| 仿真良好而真机日志差 | 力矩代理过理想、传动／反馈动态、低速摩擦、参考传感器同步 |

## 11. 最终交付什么，第一轮先做什么

建议代码项目最终至少包含以下内容；这是目标结构，不表示已经创建：

```text
piakf_reproduction/
  configs/       模型、信号、网络、KF、WMA和场景配置
  models/        固定版本的机器人模型与资产
  src/           采集、名义模型、估计器、补偿器、滤波和评价
  datasets/      按轨迹划分的测量与独立参考
  checkpoints/   动力学、TCN、MLP权重及对应预处理参数
  results/       原始输出、逐轴指标、图与失败记录
  assumptions.md 原文设置、实施假设和后续更改
  requirements-lock.txt
```

每个运行结果保存配置快照、代码／模型版本、随机种子、数据划分、权重版本、各信号时间戳、外力坐标、工具与负载边界。关键中间量包括$y,H,\widehat\tau_{err},H_e,u$、创新、协方差、TCN概率和WMA窗口长度。

**第一轮任务限定为以下五项：**

1. 创建独立环境，加载固定六轴模型，记录版本与执行器含义。
2. 建立测量包和独立参考日志，验证世界系工具点外力映射。
3. 实现独立名义动力学与12维动量KF，完成代数和补偿符号检查。
4. 跑无外力、恒力、正弦力三个场景，保留原时间戳结果。
5. 确认曲线和误差可解释后，再进入动力学训练与换向补偿。

完成阶段A—E、冻结配置与权重、输出四组消融和换向接触测试，并公开实施假设后，可以报告“基于PIAKF、在所声明条件下完成方法重实现”。若要报告“复现原论文数值”，还需相同平台／数据／配置与指标口径的进一步核对；仅使用替代模型取得接近0.43 N的数字不满足这一条件。

真机阶段优先重放同步日志并用独立F/T参考评价，再决定是否接入控制。若进一步研究装配，应另外记录任务几何、公差、初始误差、传感器、频率、成功判据、试验次数、周期时间、接触力与失败类型。原论文未报告的装配指标不能由本次估力复现补推。
